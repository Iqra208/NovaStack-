# 📖 About the Project

SoulMatch AI is an AI-inspired matchmaking platform developed to help users discover meaningful and compatible relationships through modern technology. The application provides a smooth, secure, and engaging experience with user authentication, profile management, personality-based matching, and a responsive interface.

The project includes both a **Web Application** and an **Android Application**, demonstrating practical software engineering, mobile development, and modern UI/UX design.

---

# 💡 Why I Created This Project

Many existing matchmaking platforms focus mainly on appearance and provide limited personalization.

I created **SoulMatch AI** to explore how AI-inspired recommendations and user preferences can make online matchmaking more meaningful and user-friendly.

# 🚀 Installation

## Android Version

1. Clone this repository.

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/SoulMatch-AI.git
```

2. Open the project in Android Studio.
3. Allow Gradle Sync.
4. Run the project on an emulator or Android device.

---

## Web Version

1. Clone the repository.
2. Open `index.html` in your browser.

Or deploy using **Vercel**.

---

# 🌐 Deployment

The web application can be deployed using **Vercel**.

Steps:

1. Upload the project to GitHub.
2. Import the repository into Vercel.
3. Click **Deploy**.
4. Access your live application using the generated Vercel URL.
